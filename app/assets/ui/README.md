# City backdrop

`cursed-city.png` was generated for LockLingo using OpenAI's built-in imagegen
on 2026-10-18. It is an original atmospheric background inspired by the approved
Deadlock direction, not an extracted Valve game asset. All interface text,
controls and graphs are rendered separately by Tk.

Generation prompt: a matte ink illustration of a haunted 1930s New York alley,
angular rooftops, water towers, wires and a distant railway; charcoal and smoke
brown, muted sage, sparse orange windows, mostly dark empty space at left.
No text, logos, characters, UI, metallic filigree, neon or cyberpunk styling.
