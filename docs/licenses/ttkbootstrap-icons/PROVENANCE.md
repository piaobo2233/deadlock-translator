# Bootstrap Icons 固定字体输入

本版保留 ttkbootstrap 控件渲染实际使用的字体，不改变现有主题和识别/翻译行为。

- 精确来源：ttkbootstrap **2.2.3** 的源码归档 `ttkbootstrap-2.2.3.tar.gz`，SHA-256 `31b71ca273e2cd2fc354f9f736498bb334209703aea22a0abc076b6231dcfc0f`。
- [原始源码下载](https://files.pythonhosted.org/packages/7b/36/c90cc09fc6d5b33f8b8a0cbe6d83e1e58b3df743189777245e1f18eb055a/ttkbootstrap-2.2.3.tar.gz)。源码也包含在本版 `LockLingo-1.2.1-third-party-sources.zip` 中。
- 上游目录：`src/ttkbootstrap/assets/icons/`。本机构建输入的字体、映射、度量、README 和 LICENSE 均与上述源码归档逐字节一致。
- 上游 README 记载字体内部版本为 **1.0**，经 bootstack 项目纳入；没有记载独立的 Bootstrap Icons 发布标签。本记录用 vendor 版本、固定源码与文件摘要识别输入，不猜测其标签。
- MIT 原始版权及许可见同目录 LICENSE，README 按上游原文保留。二者随包置于 `licenses/ttkbootstrap-icons/`；字体按既有收集规则位于 `_internal/ttkbootstrap/assets/icons/bootstrap.ttf`。
