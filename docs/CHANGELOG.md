# 更新日志

## 1.0.2 — 2026-10-25

- 修复截图后的遮罩层遮挡编辑器、主界面无法操作的问题。
- 接收翻译允许仍有效的消息在 12 秒上限内返回，避免 OCR 占用 4 秒预算后提前中止接口等待；不自动重发结果未知的付费请求。
- 过期 OCR 任务不再启动识别调用，避免不必要的常驻识别器降级；原有中文复核与多帧确认保留。
- 新增后台智能清理及手动入口，仅清理超过 14 天的轮转运行日志和校验通过的已成功使用安装包，保留个人资料和回退备份。
- 验证方式、更新入口及性能边界见[1.0.2 发布说明](releases/v1.0.2.md)。

- 七个功能区改为连续页面，导航跟随滚动，保留跨区草稿、原有操作和居中区域编辑器。
- 统一纸色胶囊、液体悬停、导航反馈、下拉菜单、开关与滑块光感，改善词库工具栏和小窗口布局；字体优先复用本机游戏字体，未附带字体文件。
- 主窗口保持完全不透明；修正开关滑块终点及更新按钮移出后绿色不消退的问题。
- 局内译文气泡使用暖纸底、细墨边、内沿高光与粗体文字，保留原有定位、穿透及显示寿命。
- 发布完整安装包供 1.0.0 安装版更新，补充组件元数据与第三方源码材料。验证范围见[测试说明](TESTING.md)。
