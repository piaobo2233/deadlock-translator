# 测试状态

## 公开源码基础检查

[GitHub Actions](https://github.com/piaobo2233/deadlock-translator/actions/workflows/public-checks.yml) 只执行：

| 检查 | 范围 |
| --- | --- |
| Python 语法 | 解析公开实现、脚本和测试中的 Python 文件，不启动应用 |
| 打包隐私边界 | `test_portable_build.py` 的两项标准库测试，拒绝用户 data 与嵌套配置 |
| 本地文档链接 | 检查公开 Markdown/HTML 链接的本地文件目标存在且位于仓库内；不请求外部网站，不验证页面锚点 |

不安装运行依赖，不读取用户 data，不调用翻译 API，不运行可见界面或游戏输入。徽章成功只表示上述范围通过。

本地复现命令见[贡献说明](CONTRIBUTING.md)。完整 Windows/OCR/游戏验证依赖不同环境和材料，不能将基础 CI 当成覆盖率或实际效果证明。

## 尚未验收

真实游戏快捷键回填/自动发送、整局识别覆盖率与端到端延迟、完整 DPI/小窗口布局、其他屏幕比例和性能均需要进一步测试。首字母大写等正常短句仍可能漏译。
