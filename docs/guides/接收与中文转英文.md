# 异锁聊天翻译助手：接收与输入翻译

本说明对应当前源码。左侧导航为接收翻译、发言翻译、词库、识别与显示、翻译接口、设置。源码修改后，空闲时关闭旧助手，再双击项目根目录的 `启动.vbs`；已安装包不会随源码自动更新。

## 屏幕接收

当前源码在空闲时降低探测和 OCR 频率，出现疑似新聊天后短时加速，连续新内容续期；已有字幕仍保持必要的视觉跟踪。活跃期也限制 OCR 回退并发，具体节奏及实机对照见[识别负载与掉帧对照](识别负载与掉帧对照.md)。

助手默认在游戏前台识别英语、西班牙语、葡萄牙语、法语、德语、日语、韩语和俄语聊天，无需逐个启用来源语言，默认输出简体中文。接收页“收到的消息译成”为单选，修改后重启助手；非中文目标使用独立缓存，不复用中文词库。

含假名的日文、韩文、俄文及中外文混合正文进入正常翻译判定，纯中文保留原样；用户名不决定正文语言。中文里的位置字母或单个游戏名不会独自触发翻译。只有汉字的短句可能同时属于中文或日文，此时保守保留原文。八语已验证系统字体合成素材，真实对局中的字体、透明度、密集消息和错字仍需实测；并非任意世界语言均受支持。缺少模型会明确提示，不静默缩减语言。

识别设置位于“识别与显示”。默认按主屏物理像素生成参考范围；可导入完整原始局内截图或截取当前游戏画面，拖动调整并保存个人区域。不开游戏也能设置，个人区域仅在同尺寸画面启用；恢复默认可清除个人记录。详见[个人识别区域](个人识别区域.md)。

“测试当前游戏画面”隐藏面板及旧预览，留出3秒切回游戏，截图后再打开只读裁图与正文OCR结果；编辑器的“本地测试”直接读取当前草稿范围。不上传截图、不调用翻译API，也不将单帧测试写入待审核。大区域只用于搜索，只有通过既有几何检查的正文小块才进入OCR；未找到正文时明确提示。

运行时分辨率变化会重建采集源，无需重启。画面比例、预设或游戏客户区不能确认覆盖主屏时暂停识别并提示，不回退全屏OCR。首轮范围是主屏16:9全屏/无边框；三种分辨率已有坐标夹具验证，实际独占全屏、DPI、黑边和性能仍需实机验收，不能据此宣称超宽屏、窗口化或副屏支持。

译文显示仅保留字号设置。宽度、容纳数量与停留由正文、空间和原气泡有效性自动安排；原气泡失效即不能显示，新消息不续活失效译文。放不下时接收翻译页提示空间不足。

接收链持续实时识别。旧手动模式兼容为实时模式，旧识别快捷键不再注册；已有字幕继续按原气泡视觉寿命显示。

识别效果和翻译延迟仍需实际对局验证。字幕可能因识别失败、质量检查不通过或超时而未显示，不能仅凭已显示的字幕判断整体效果。

## 游戏复制中文与面板预览

在“发言翻译”页主动开启“游戏复制中文自动译英”（默认关闭，即时生效）。在游戏原生聊天框输入中文并提交输入法候选，再自行 Ctrl+A/C 复制。助手确认前台游戏与剪贴板所有者一致后，固定中文译英；成功提示“已复制英文，可 Ctrl+V 粘贴”后，自行 Ctrl+A/V 粘贴并决定是否回车发送。

成功会覆盖系统剪贴板，译文保留供粘贴，不恢复旧内容。关闭时不读内容、不请求翻译。来源未知、其它程序来源、纯英文或图片会跳过；新复制都会取消旧输出。连续复制只保留最新句；切出游戏、暂停或关闭后，旧结果不会写入，返回后请重新复制。该入口不注入按键，不注册发言或识别快捷键。旧 auto_send、热键字段仅保留兼容。

输入须含中文且为 1–500 字。功能不监测输入框编辑，编辑后需要新译文请再次复制；游戏内其它用途的中文复制也可能触发。已发请求无法保证立即中断，仍照实记账。现有私有请求台账可保存原文、合格译文及请求状态；默认诊断和反馈包排除正文及原始请求库。不要公开 data 或完整备份。

也可继续在发言翻译页输入中文、点击“翻译”，检查预览后点击“复制”，自行粘贴发送。“面板发言目标语言”控制该面板，游戏复制入口固定英语，不改变接收或面板的语言偏好。历史原文恢复记录仍保留，新剪贴板入口不另存整段正文到会话面板。

两个入口沿用现有接口、模型、质量与费用保护。关闭在线翻译后不发起新请求，已有可核对的合格结果可复用；结果未知时仍阻止同句自动重发。本入口目前复用手动翻译服务的合格请求恢复，不承诺接收链的中文词库会反向翻译。

当前验证范围与未完成项见[1.0.0 发布说明](../releases/v1.0.0.md)。本机真实复制/粘贴已有使用反馈；连续使用及接收链联合验收仍需分别登记。源码改动不会更新已安装包。

## 服务配置与费用

在翻译接口页选择 DeepSeek 预设可填入地址和默认模型；自定义兼容接口允许编辑完整 `chat/completions` 地址和模型。两个方向共用这份服务配置。“测试连接（可能计费）”发送一次有界测试请求，展示明确结果；不自动重试，不显示密钥。测试可用未保存的接口和模型草稿。普通设置保存不写入环境变量 Key，环境变量仍优先；接口地址、模型和 Key 统一点击“保存”才落盘，失去焦点不保存；空白 Key 保留原密钥。保存结果与运行时是否已应用分别反馈。

当前不提供专门会话回看界面；原文恢复仍可在发言翻译页使用，既有本地记录保留。

请求结果无法确认时，保留记录，避免自动重复请求。重启不会自动解除该保护；请先向服务商核对，处理方法见[开发说明](../DEVELOPMENT.md#请求结果不明时的处理)。

## 待审核

待审核列表持续显示具有有效原始绘制回执、版本及请求关联且通过质量检查的API候选。显示记录不能证明游戏画面最终可见，遇到遮挡时应以原画面为准。

无需点击“开始新对局”。合格未处理项跨局、切前台及重启持续保留，人工接受、编辑或忽略后进入已处理；不会猜测真实对局开始，也不会把旧回执伪装成新会话绘制。

未显示、质量检查失败及缺少显示证据的旧记录不会默认列出，也不会自动删除。诊断与测量方法见[开发说明](../DEVELOPMENT.md)。

接收页默认优先显示当前问题，累计识别、翻译、绘制及失败原因在“诊断详情”中展开。费用使用接收翻译页的单一数字摘要和可展开七天列表，约五秒自动刷新。金额来自真实请求用量与请求时单价的估算；小额正数不会显示成精确零，无记录、已知零、部分已知、未知和记录不可用分别提示。请求次数含重试，任务结果也包含输入与连接测试；本地命中是处理次数。未运行或运行快照过期/来源不匹配时使用落盘记录，界面标明来源及读取/更新时间；不是供应商实扣账单。
