# 异锁聊天翻译助手：接收与输入翻译

本说明对应当前源码。左侧导航为接收翻译、发言翻译、词库、识别与显示、翻译接口、设置。源码修改后，空闲时关闭旧助手，再双击项目根目录的 `启动.vbs`；已安装包不会随源码自动更新。

## 屏幕接收

当前源码在空闲时降低探测和 OCR 频率，出现疑似新聊天后短时加速，连续新内容续期；已有字幕仍保持必要的视觉跟踪。活跃期也限制 OCR 回退并发，具体节奏及实机对照见[识别负载与掉帧对照](识别负载与掉帧对照.md)。

助手默认在游戏前台实时识别英文聊天，输出简体中文。聊天正文含汉字时整条跳过，包括中外文混合消息；用户名不属于正文。接收翻译页可单独选择接收目标语言，修改后重启助手。非中文接收目标使用独立缓存，不复用中文词库。

识别设置位于“识别与显示”。默认自动读取主屏物理像素，按16:9搜索预设适配；也可选择1920×1080、2560×1440、3840×2160。预设必须匹配实际主屏像素，不改变Windows或游戏显示设置。旧手工选区保留供回退，新版不再使用，也不提供拖框入口。

“测试识别”隐藏面板及旧预览，留出3秒切回游戏，截图后再打开只读裁图与正文OCR结果。不上传截图、不调用翻译API，也不将单帧测试写入待审核。大区域只用于搜索，只有通过既有几何检查的正文小块才进入OCR；未找到正文时明确提示。

运行时分辨率变化会重建采集源，无需重启。画面比例、预设或游戏客户区不能确认覆盖主屏时暂停识别并提示，不回退全屏OCR。首轮范围是主屏16:9全屏/无边框；三种分辨率已有坐标夹具验证，实际独占全屏、DPI、黑边和性能仍需实机验收，不能据此宣称超宽屏、窗口化或副屏支持。

译文显示仅保留字号设置。宽度、容纳数量与停留由正文、空间和原气泡有效性自动安排；原气泡失效即不能显示，新消息不续活失效译文。放不下时接收翻译页提示空间不足。

可切换“仅按快捷键识别”，默认快捷键 `Ctrl+Alt+R`。手动模式仅在按下后短暂采样并 OCR，以复用原有多帧确认；不会补回按键前已消失的聊天。已有字幕继续按原气泡视觉寿命显示，悬浮窗保持非激活与鼠标穿透。模式和快捷键修改后重启助手。

识别效果和翻译延迟仍需实际对局验证。字幕可能因识别失败、质量检查不通过或超时而未显示，不能仅凭已显示的字幕判断整体效果。

## 游戏输入与面板预览

在游戏聊天框打完中文后，按 `Ctrl+Alt+T`（可配置）：助手全选、复制、翻译，核对输入后回填原聊天框。默认不按发送键；在“发言翻译”显式打开“自动发送”，下次触发才会在回填读回确认后按 Enter。请先在实际游戏窗口核对输入和快捷键兼容性。

翻译失败、超时、输入修改、点击鼠标或焦点转移时取消自动回填/发送；切走再切回也会取消。不会主动把焦点切回游戏。发言翻译页的“复制上次输入原文”可恢复最近游戏输入，包括正在翻译及失败时的原文。专门的会话回看界面已移除，既有记录未清空。成功的复制/粘贴会短暂使用系统剪贴板；仅在期间未被其他程序改动时恢复原有文本剪贴板，不保留图片等其他剪贴板格式。

也可在发言翻译页输入最多 500 字，点击“翻译”，检查预览后点击“复制”，自行粘贴发送。输入需包含中文，屏幕接收的中文过滤规则不影响此功能。“发言目标语言”默认英语，可与接收目标分别选择。

功能使用设置中的 API Key、接口、模型和联网开关。关闭在线翻译后不发起新请求，已保存的翻译仍可本地使用。API 用量由服务商计费。

切页保留本次打开软件期间的原文、预览和未保存接口草稿。修改原文、目标语言或接口会使旧预览失效；预览可保留查看，过期结果不能复制。面板预览只在点击复制时修改剪贴板；游戏快捷键流程会自动复制与回填。

## 服务配置与费用

在翻译接口页选择 DeepSeek 预设可填入地址和默认模型；自定义兼容接口允许编辑完整 `chat/completions` 地址和模型。两个方向共用这份服务配置。“测试连接（可能计费）”发送一次有界测试请求，展示明确结果；不自动重试，不显示密钥。测试可用未保存的接口和模型草稿。普通设置保存不写入环境变量 Key，环境变量仍优先；接口地址、模型和 Key 统一点击“保存”才落盘，失去焦点不保存；空白 Key 保留原密钥。保存结果与运行时是否已应用分别反馈。

当前不提供专门会话回看界面；原文恢复仍可在发言翻译页使用，既有本地记录保留。

请求结果无法确认时，保留记录，避免自动重复请求。重启不会自动解除该保护；请先向服务商核对，处理方法见[开发说明](../DEVELOPMENT.md#请求结果不明时的处理)。

## 待审核

待审核列表持续显示具有有效原始绘制回执、版本及请求关联且通过质量检查的API候选。显示记录不能证明游戏画面最终可见，遇到遮挡时应以原画面为准。

无需点击“开始新对局”。合格未处理项跨局、切前台及重启持续保留，人工接受、编辑或忽略后进入已处理；不会猜测真实对局开始，也不会把旧回执伪装成新会话绘制。

未显示、质量检查失败及缺少显示证据的旧记录不会默认列出，也不会自动删除。诊断与测量方法见[开发说明](../DEVELOPMENT.md)。

接收页默认优先显示当前问题，累计识别、翻译、绘制及失败原因在“诊断详情”中展开。费用使用接收翻译页的单一数字摘要和可展开七天列表，约五秒自动刷新。金额来自真实请求用量与请求时单价的估算；小额正数不会显示成精确零，无记录、已知零、部分已知、未知和记录不可用分别提示。请求次数含重试，任务结果也包含输入与连接测试；本地命中是处理次数。未运行或运行快照过期/来源不匹配时使用落盘记录，界面标明来源及读取/更新时间；不是供应商实扣账单。
