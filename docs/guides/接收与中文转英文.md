# 接收与中文转英文

更新源码后，正常退出并重新打开根目录 `启动.vbs`。主面板仍是翻译、词库、设置三页。

## 屏幕接收

- 接收英语、西班牙语、葡萄牙语、法语、德语，输出简体中文。
- 聊天正文含任意汉字时，整条跳过，包括中外文混合消息。用户名不在正文范围内。
- 保留三个不同采样帧的实际 OCR 确认、正文几何检查、视觉连续性与独立源图复核。缓存不增加确认票。
- 本机安装目录含 `libtesseract-5.dll` 时，使用隐藏的常驻辅助进程，识别卡住可终止。源码和首个测试包均支持该辅助进程；DLL 不可用时采用有超时保护的命令行路径，并在诊断说明后备状态。
- 首选正文与独立源图读数一致时停止更多变体；短缩写读不清时保留原有英文后备策略。源图汉字检查不使用用户词表。
- `ocr_interval` 作为最小处理周期，整轮 OCR 已耗掉的时间不再额外等待。普通启动读取该配置；确认票数至少为 3。
- 新字幕从首次候选画面起最多等待 4 秒，API 等待及第一次绘制都检查截止时间；已按时显示的字幕仍按原气泡寿命停留。

程序计时的起点是检测到的候选帧，晚于原文字真正出现的时间仍有可能。90% 在 2 秒内的目标需要对一整局原画面人工标注并将漏译计入分母，目前未做新对局验收。

## 中文转英文

在翻译页的“中文转英文”输入最多 500 字，点击“翻译为英文”，核对预览后点击“复制英文”，自行粘贴发送。输入框包含中文即可，屏幕接收的中文跳过规则不影响这里。

此功能读取设置中的 API Key、接口、模型、联网开关、价格和预算。关闭在线翻译后不发新请求；有效旧结果仍可本地复用。源文/目标文方向及用途有独立请求身份，不写正式词库或屏幕待审核队列。费用沿用请求台账，未知结果不会自动重发。

修改输入会撤销旧预览与复制资格。后台返回的旧结果、离开页面后的结果不会进入新预览。点击复制之前不改剪贴板，不自动操作游戏。

手动翻译以 5 秒内完成为目标，接口等待设为 4.5 秒，为本地处理和界面刷新留出时间，不自动重试。预览不受屏幕气泡的寿命限制，接口已返回的有效结果不会被误作气泡过期。接口超时与配置改变分别提示，不会再把已发出的请求写成“气泡已失效、未请求 API”。接口超时后无法确认是否计费，同一句会保留防重发记录，重启也不会自动清除。网络与服务商尾延迟无法由本机保证，缩短超时不等于所有翻译都能在 5 秒内成功。

旧的结果未知记录可在源码目录运行 `python -m app --pending-requests` 查看。先在接口服务商核对；确认未计费后才用 `python -m app --release 请求编号` 允许再试一次，或用 `python -m app --abandon 请求编号` 放弃。处理记录不会自动发起翻译。不要通过删除请求文件解除保护。

## 待审核

默认列表要求：本次运行的具体消息身份有实际 Tk 绘制回执，且候选通过质量检查。软件不能凭这个回执证明游戏合成器已经将像素呈现到显示器，遇到遮挡仍以原画面为准。

助手启动时创建首局审核。下一局开始时，在词库页点击“开始新对局”；助手确认后默认列表切换到新局，旧记录保留。切换前已经出现的消息，即使迟到绘制，也不会混入新局。游戏没有可靠的开始/结束事件可用，因此跨局边界需要这次点击，程序不把切出游戏误判为新对局。

质检失败、未显示、旧请求恢复记录继续保留，不自动删除、不默认显示；可以通过诊断文件与 `python -m app --review-pending` 检查。没有可靠显示证据的旧记录不会被推定为已显示。

## 测量与复核

私有 `backups/development/recognition-recent/` 保留候选图及生命周期记录，含首次候选帧、确认与分段耗时。`data/runtime.json` 的 `latency_drawn_ms` 按本地/API 保留最近 512 个绘制样本；这是成功显示样本，不能单独证明真实聊天覆盖率。

开发工具 `tools/benchmark_receive.py --output 私有目录/ocr.json` 比较英文 CLI、五语言 CLI 与常驻路径。它使用现有裁图和合成语言样本，不调用翻译 API，不替代实机对局。

整局验收由 `verify/latency_acceptance.py labels.json --output report.json` 计算。输入为 `{"messages":[{"id":"m1","eligible":true,"appeared_at":1.0,"drawn_at":2.0,"route":"api"}]}`。时间统一使用原录像秒数，未显示记 `drawn_at:null`；`eligible` 依据原画面，原文无中文却被误判跳过的消息仍需记为符合条件且漏译。工具将未译消息保留在 90% 的分母中，同时报告实际超过 4 秒的显示。
