# 异锁聊天翻译助手 1.0.0-test.1 接收与中文回复

## 屏幕接收

助手默认在游戏前台识别英语、西班牙语、葡萄牙语、法语和德语聊天，输出简体中文。聊天正文含汉字时整条跳过，包括中外文混合消息；用户名不属于正文。

识别效果和翻译延迟仍需实际对局验证。字幕可能因识别失败、质量检查不通过或超时而未显示，不能仅凭已显示的字幕判断整体效果。

## 中文转英文

在翻译页输入最多 500 字，点击“翻译为英文”，检查预览后点击“复制英文”，自行粘贴发送。输入需包含中文，屏幕接收的中文过滤规则不影响此功能。

功能使用设置中的 API Key、接口、模型和联网开关。关闭在线翻译后不发起新请求，已保存的翻译仍可本地使用。API 用量由服务商计费。

修改输入会使旧预览失效。复制前不会修改剪贴板，助手不会自动向游戏发送消息。

请求结果无法确认时，保留记录，避免自动重复请求。重启不会自动解除该保护；请先向服务商核对，处理方法见[开发说明](../DEVELOPMENT.md#请求结果不明时的处理)。

## 待审核

待审核列表默认显示本局有显示记录且通过质量检查的候选。显示记录不能证明游戏画面最终可见，遇到遮挡时应以原画面为准。

下一局开始时，在词库页点击“开始新对局”。切换后旧记录保留，默认列表显示新局记录；助手不会自动判断对局边界。

未显示、质量检查失败及缺少显示证据的旧记录不会默认列出，也不会自动删除。诊断与测量方法见[开发说明](../DEVELOPMENT.md)。
