# 异锁聊天翻译助手 1.0.0-test.3 使用说明

运行环境：Windows 10/11 64 位。测试包包含 Python 运行环境，无需另行安装 Python。

## 安装与启动

1. 完整解压 ZIP 到可写的普通文件夹，保留 `DeadlockTranslate.exe` 和 `_internal`，勿在压缩软件中直接运行。
2. 未安装 Tesseract OCR 时，运行 `首次安装OCR` 文件夹中的安装器，保留默认位置和 English 组件。助手已附带所需识别模型，无需额外下载语言。
3. 双击 `启动.vbs`。直接运行 exe 会显示日志控制台。
4. 在“翻译接口”填写自己的 API Key、接口和模型，点击保存；在“接收翻译”按需开启联网翻译。初始联网开关关闭；API 用量由服务商计费。
5. 打开游戏。默认只在游戏前台识别；显示“等待游戏”时不会翻译桌面文字。
6. 关闭主窗口默认退出助手。若设置为“后台运行”，关闭窗口仅关闭面板；本测试包不附托盘组件，请保留默认退出方式。

## 功能与限制

可接收英语、西班牙语、葡萄牙语、法语和德语聊天，翻译为简体中文；正文含汉字时整条跳过。发言翻译页支持中文预览与复制；游戏内快捷键回填和可选自动发送仍需实际游戏验收，自动发送默认关闭。

识别效果和翻译延迟仍需实际对局验证，可能漏译、误识别或超时。网络与服务商响应会影响在线翻译。请求结果无法确认时，保留记录，避免自动重复请求；不要通过删除记录解除保护。

操作说明见[接收与中文回复](接收与中文转英文.md)，测试记录及详细机制见[开发说明](../DEVELOPMENT.md)。测试包未签名，可按下载页的 SHA-256 核对文件。

## 分享与反馈

分享完整 `DeadlockTranslator-1.0.0-test.3-windows-x64.zip`，可附同名 `.sha256`。程序运行后会创建个人 `data` 和 `.temp`，请勿重新压缩使用后的目录。

反馈请附版本、Windows 版本、分辨率与缩放、游戏显示模式、代理情况及复现步骤。设置页可导出反馈 ZIP，提交前请自行检查；勿发送密钥、完整 `data` 或私人聊天，截图请遮挡昵称。

OCR 在本机完成；开启 API 后，待翻译文字会发送给配置的服务商。安装器来源见包内说明和 [Tesseract Windows 安装说明](https://github.com/UB-Mannheim/tesseract/wiki)。本项目与 Valve 无关联，非官方产品。
