# 异锁翻译助手 1.0.0 首个测试包

这是 Windows 10/11 64 位测试版，需要实际对局继续验证识别率和延迟。测试者无需安装 Python。

## 第一次使用

1. 完整解压压缩包到可写的普通文件夹，不要在压缩软件里直接运行，也不要只取出 exe。
2. 若未安装 Tesseract OCR，先运行 `首次安装OCR` 文件夹中的官方安装器，保留默认安装位置和 English 组件。本助手已附带所需六种识别模型，无需勾选额外下载语言。OCR 已安装者可以跳过。
3. 双击 `启动.vbs` 打开助手。也可直接运行 `DeadlockTranslate.exe`，会多出日志控制台。保留 `_internal` 文件夹。
4. 在设置中填写自己的 API Key，核对接口和模型，再打开在线补充翻译。初始不联网；每个人承担自己的 API 用量。不要共用作者的密钥。
5. 打开游戏进行测试。默认只在游戏处于前台时识别；主面板显示“等待游戏”时不会翻译桌面文字。
6. 点主窗口右上角关闭按钮退出助手。正在处理的识别或请求需先收尾保存；设置为“后台运行”时关闭窗口只关闭面板，需重新打开并恢复“退出助手”。本测试包不附系统托盘组件，正常使用请保留默认退出方式。

## 本版可测试的功能

- 英语、西班牙语、葡萄牙语、法语、德语聊天转简体中文；聊天正文含汉字时整条跳过。
- 中文输入转英文，检查预览后点击复制，再自行粘贴到游戏发送。
- 三个不同采样帧确认；首次候选起超过 4 秒的新字幕停止显示。
- 待审核默认限定当前局实际绘制且质检通过的候选；下一局在词库页点击“开始新对局”。

5 秒内完成手动翻译是目标，不是服务商成功响应保证。接口等待 4.5 秒，不自动重试。超时后若无法确认是否计费，同句会保留防重发保护，不能靠重启清除。网络代理、服务商拥堵或限流都可能影响 API。首版尚未证明整局 90% 的消息在 2 秒内显示。

## 怎么反馈

请说明测试版本、Windows 版本、分辨率与缩放比例、游戏显示模式、是否使用代理、出现问题的操作步骤和大致时间。可在设置的“反馈与排查”导出本地反馈 ZIP，自行检查后发送。不要发送 API Key、整个 data 文件夹或原始聊天记录；截图中的昵称请遮挡。

本测试包尚未进行代码签名，也未在所有 Windows 硬件上验证。遇到启动拦截时先核对来源和压缩包 SHA-256，不要关闭系统防护。

## 应该分享什么

只分享生成的完整 `DeadlockTranslator-1.0.0-test.1-windows-x64.zip`，可同时附 `.sha256` 校验文件。包里包含程序、Python 运行依赖、识别模型、使用说明、许可证及原始 OCR 安装器。首次运行会在程序旁创建用户自己的 `data` 和 `.temp`，它们不属于初始分享包。已经运行过的文件夹请勿重新压缩发送，以免带出密钥和私人记录。

OCR 安装器来源：[Tesseract 官方项目 Windows 下载](https://github.com/UB-Mannheim/tesseract/wiki)。本助手与 Valve 无关联，非官方产品。
