# 锁语 · LockLingo 1.0 安装版使用说明

本包为 `1.0.0`。当前请选择纯英文可写目录，例如 `D:\LockLingo`；中文路径仍有 OCR 初始化兼容性风险。跨设备、完整对局和真实升级恢复验证边界见[发布说明](../releases/v1.0.0.md)。

运行环境：Windows 10/11 64 位。安装包与测试 ZIP 都已内置 Python 运行环境和 OCR；**不需要另外安装 Python 或 Tesseract OCR**。

## 推荐：用安装包（一体化安装）

1. 双击 `LockLingo-<版本>-setup.exe`，版本以同目录摘要文件及安装界面为准。
2. 每次交互安装都可选择目录，上次路径仅作为默认值。请选择纯英文路径，无需管理员权限；安装完成会在桌面和开始菜单创建「锁语 · LockLingo」快捷方式。
3. 首次启动会出现「首次设置」：选择翻译服务商、填写你自己的 API Key（预设会带出地址与模型，自定义接口可改）；也可以点「跳过」先用离线词库。
4. 在首次设置或设置页准备本机游戏资料；完成后重启。资料来自自己的游戏安装，游戏更新后需重新准备，详见[说明](本机游戏资料.md)。
5. 回到首页后，需要在线翻译时再打开「联网翻译」开关。接口按服务商计费，程序不会在打开页面时发请求。
6. 打开游戏。默认只在游戏前台识别；显示「等待游戏」时不会翻译桌面文字。可在“识别与显示”导入截图调整区域。游戏中文译英默认关闭，需在“发言翻译”主动开启；自行复制，成功后自行粘贴和发送，助手不自动按键或发送。

升级：再次运行新版本安装包即可覆盖程序文件；`<安装目录>\data` 里的配置、密钥、词库和记忆会保留。

卸载：从「设置 → 应用 → 已安装的应用」卸载。卸载默认**保留**个人数据；问到是否保留时选「是」。删除数据不可恢复。

## 便携 ZIP（免安装）

1. 完整解压 ZIP 到可写的普通文件夹，保留 `LockLingo.exe`、`DeadlockTranslate.exe`、`_internal` 和 `ocr`，不要在压缩软件里直接运行。
2. 双击 `LockLingo.exe`，不显示日志控制台。`DeadlockTranslate.exe` 用于命令行诊断与后台 OCR，请一并保留。
3. 其余步骤与安装包相同。程序数据在其所在目录的 `data` 文件夹。

## 从旧测试版（test.1 / test.2 / test.3 解压包）迁移

旧包要求手动安装 OCR，新包已内置，不需要再装。想保留旧词库/记忆/密钥时：

1. 先退出新旧程序（托盘或窗口），将旧目录里的整个 `data` 另行备份。
2. 新目录若已有 `data`，也先单独备份；确认要沿用的数据后，再把整份 `data` 复制到新安装目录（或新解压目录）下。不要只拷其中一两个文件，也不要直接覆盖未经备份的新记录。
3. 启动新程序确认词库、记忆和设置都在。

程序不会自动猜测或搬运旧目录——同一台机器上可能有多份旧包，静默猜测比让用户手动复制更危险。

## 功能与限制

默认接收英语、西班牙语、葡萄牙语、法语、德语、日语、韩语和俄语，译成所选的一种语言。纯中文保持原样；含假名日文和中外文混合正文有对应处理。面板发言可选择目标语言并检查预览；游戏复制中文固定译英，用户自行粘贴发送。

识别效果和翻译延迟仍需实际对局验证，可能漏译、误识别或超时。网络与服务商响应会影响在线翻译。请求结果无法确认时，保留记录，避免自动重复请求；不要通过删除记录解除保护。多显示器只抓主屏。

## 分享与反馈

分享原始发行安装包或 ZIP 与同名 `.sha256` 摘要。程序安装/运行后会创建个人 `data`，请勿重新压缩正在使用中的数据目录再分发。

反馈请附版本、Windows 版本、分辨率与缩放、游戏显示模式、代理情况及复现步骤。设置页可导出反馈 ZIP，提交前请自行检查；勿发送密钥、完整 `data` 或私人聊天，截图请遮挡昵称。

## 来源与许可

OCR 运行时来自固定的 MSYS2 二进制包；来源和逐文件摘要见包内 `OCR-RUNTIME.txt` 及源码中的 `scripts/ocr-runtime-manifest.json`，各组件原始许可见 `licenses/tesseract/`。识别模型来自 tessdata_fast 固定提交；对应 OCR 源码以同版本独立附件提供。完整第三方清单见 `THIRD-PARTY-NOTICES.md` 与 `licenses/`。
