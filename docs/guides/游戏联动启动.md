# 游戏联动启动

在设置的“个人偏好”中开启 **游戏启动时启动助手**。默认关闭，由你选择是否启用；安装和首次运行不会自动开启。

开启后立即开始监听，以后登录 Windows 时也会启动轻量监听程序。检测到 `deadlock.exe` 启动后，通常在约 3 秒内开始启动助手；助手本身的初始化还需要时间。如果开启时游戏已经运行，也会尝试启动一次。没有游戏时，监听程序不运行 OCR、界面或翻译请求。

已有助手在运行时不会重复启动。游戏运行期间手动退出助手后，不会被反复拉起；游戏退出后下一次启动才会再次触发。游戏关闭不会强制关闭助手，仍按你原来的关闭窗口设置操作。

关闭开关会删除属于本安装的登录监听入口，监听程序将在几秒内退出；已经运行的助手不会被强制结束。助手启动后仍遵守现有联网翻译开关、预算及请求保护，不会因为开启游戏联动而额外打开联网翻译。

该功能适用于 Windows，使用当前用户的启动文件夹，不要求管理员权限。系统策略仍可能禁止创建启动项或运行脚本，设置失败会在界面显示原因。监听入口文件为当前用户启动文件夹中的 `LockLingo-GameWatcher.vbs`；只有内容属于当前安装时才能修改或删除。若原来启用了开机直接启动，升级后首次启动助手会清理本安装的精确旧命令，不操作其他程序的启动项，也不会因此自动开启新的游戏监听；需要时请主动开启本选项。

如果使用源码版，移动项目或 Python 环境前先关闭此开关，移动完成后重新开启。手动安装升级或卸载前，也请先关闭此开关并退出助手；软件内置更新期间监听会自行停止，更新后启动助手会恢复已开启的监听。

启动失败的诊断会尽可能写入 `data/game-start.log`。本次源码同步未更新安装包，已有安装版需要包含此功能的新构建才会出现这个选项。
