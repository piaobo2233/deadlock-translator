# 准备与更新本机游戏资料

本版本不附带整理出的游戏名称和快捷消息数据。安装完成后，在「首次设置」或「设置 → 游戏资料」点击「准备／更新游戏资料」。程序会查找 Steam 的 Deadlock 安装，读取本机文件，不联网、不调用翻译接口。

找不到时，点击「选择游戏文件夹」，选择 Steam 中的 `Deadlock`、`game` 或 `game/citadel` 文件夹。等待 Steam 更新结束后再准备。后台处理时可以继续使用界面，保存成功后重启助手生效。

两份资料以一个完整快照保存在本机 `data/game-resources.json`，包括游戏版本和源文件摘要。游戏升级或源文件变化后，旧资料停用；回到设置重新准备。生成或保存失败会保留原缓存，不改动个人词库、记忆和接口配置。

没有游戏或尚未准备时，助手仍可启动，通用词库、个人记忆、缓存和按需联网翻译可用；官方名称参考及对应快捷消息模板暂不可用。当前解析器遇到未知游戏资源格式会报告失败，不猜测内容。资料准备成功不表示所有快捷消息已在实际游戏中验证启用。

反馈时请提供助手版本、游戏版本、系统缩放和问题说明；不要上传整个 `data` 文件夹、API Key、私人聊天或生成的游戏资料。
