# 个人识别区域

在“识别与显示”选择“导入局内截图”。无需启动游戏；请选择自己保存的完整原始 PNG/JPEG，不要使用裁剪、缩放或拉伸后的图片。尺寸与当前桌面不同也能设置，个人区域只在同尺寸的游戏画面中启用。

编辑器可拖动整框、四边或四角，滚轮缩放、右键拖动画面。框内点击可定位下方局部放大；Tab 轮换手柄，方向键每次调整 1 个原图像素，Shift 每次 10 像素。坐标详情提供整数输入。参考范围、当前设置、撤销编辑只改变草稿；取消和退出不保存。

区域要覆盖两队聊天可能出现的位置，给长句与多条堆叠消息留空间。“本地测试”只检测当前草稿并尝试单帧 OCR，不需要翻译 API，不保存文字。没有聊天也能保存；检测到候选不代表完整覆盖。确认图片完整后点击“保存区域”；若已人工核对当前截图的聊天范围，可以另行勾选，但这仍不能保证后续所有聊天。

“已保存”与“已启用”分开显示。游戏未启动、未在前台、尺寸不匹配或采集未确认时保留等待状态。进入主屏全屏/无边框的同尺寸游戏画面，并收到当前运行采集回执后才显示启用。换尺寸时保留个人记录并回退参考范围；恢复原尺寸会重新核对。

“恢复默认区域”清除个人记录；“参考范围”只恢复编辑草稿。更换 HUD/UI 设置后请重新导入或截取。个人区域只修正搜索边界，字号过小仍可能影响正文检测。本版没有自动 HUD 定位、多尺寸档案或窗口化/副屏映射。

截图只在编辑会话内存中使用，不复制原图，不保存路径、缩略图或 OCR 原文。重开页面显示标有“布局示意，非当前截图”的中性轮廓。导入上限为 50 MB、4000 万像素、单边 12000 像素；动画、坏图或无法建立最小区域的微小图会被拒绝。带方向标记的图规范化后仅供预览，保存需重新选择游戏原图。

## 开发验收

`verify/calibration_coverage.py` 用独立人工标注检查当前原图的可见聊天覆盖，不能用同一个检测器的候选充当真值。私有标注与图片放入已忽略的 `backups/development/`；样本编号、设备/采集会话、布局（4+4、6+6 或未知）、开发/留出分组由人工登记。同一会话不跨分组，不把缩放合成图算作真实设备。

标注 JSON 示例（虚构坐标，无聊天时 `chat_boxes` 为 `[]`）：

```json
{"screen":[1920,1080],"chat_boxes":[[300,200,650,260]],"margin":8}
```

运行 `python -X utf8 verify/calibration_coverage.py --image 原图.png --calibration 单份区域记录.json --truth 私有标注.json`。输入区域记录为 `capture_calibration` 对象本身；不读取真实配置或写入应用数据。仅输出尺寸、范围、计数及未覆盖的标注索引。空聊天输出待验证，不签收未来聊天或真实游戏性能。

正式验收仍需真实问题设备，以及 1080p/1440p/4K、16:10、超宽、100%/125%/150%/200% DPI 的实测记录；另测首次用户任务耗时和个人区域相对基线的候选、误报与 p95 时间。缺少素材的格子标为未验证。
