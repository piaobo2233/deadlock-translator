# 安装与首次使用（锁语 · LockLingo）

面向最终用户的完整安装说明。测试版下载与校验见 [Releases](https://github.com/piaobo2233/deadlock-translator/releases)；测试包内附的简版说明是 `先读我.md`（即[首版测试与分享](首版测试与分享.md)）。

本文描述 test.4 新安装版。本地候选包尚待干净 Windows 10/11 验收与 OCR 传递组件许可核对，未公开发布；此前 test.3 及更早的 ZIP 仍需另装 OCR。

## 系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11，64 位 |
| 权限 | 普通用户即可，**不需要管理员权限** |
| Python / OCR | **不需要另外安装**；安装包和测试 ZIP 都自带 Python 运行环境和 OCR 运行时 |
| 翻译接口 | 自备 API Key（DeepSeek 或任意 OpenAI 兼容接口）；不填也能用离线词库 |

## 用安装包安装（推荐）

1. 下载 `LockLingo-<版本>-setup.exe`，双击运行。安装器界面为简体中文。
2. 默认安装目录 `%LOCALAPPDATA%\Programs\LockLingo`（即 `C:\Users\<用户名>\AppData\Local\Programs\LockLingo`），
   也可以改到别的可写目录；安装不需要管理员权限。
3. 安装完成后桌面和开始菜单会出现「锁语 · LockLingo」快捷方式。可以直接勾选启动，
   或之后双击桌面图标。
4. 如果助手正在运行，先将设置中的「关闭窗口时」设为「退出助手」，再关闭主窗口；有托盘时也可右键退出。
   安装器**不会强制关闭**正在运行的助手，也不会结束游戏。

### 升级

再次运行新版本安装包即可，会覆盖程序文件、保留个人数据。个人数据统一在
`<安装目录>\data`：配置、API Key、词库、翻译记忆、统计和审核记录。

### 卸载

「设置 → 应用 → 已安装的应用 → 锁语 · LockLingo → 卸载」。卸载时如果存在个人数据，
会询问是否保留：

- 选「是」（默认推荐）：只删程序，`data` 保留；重装后可继续使用。
- 选「否」：同时删除 `data`，**不可恢复**。

## 首次启动：填自己的 API Key

第一次启动会打开「首次设置」页：

1. **选择翻译服务商**：预设「DeepSeek」会带出官方接口地址与默认模型；
   「自定义兼容接口」可自己填完整 `chat/completions` 地址和模型名。
2. **填写自己的 API Key**。密钥只保存在本机 `data\config.json`，界面上不回显已保存的值，
   也不会写进日志或截图。
3. 点「保存并开始」。保存本身不联网；只有你主动点「测试连接（可能计费）」才会发一次
   有超时、不重试的测试请求。
4. 回到首页后，需要在线翻译时再打开右侧「联网翻译」开关。默认是关闭的：
   此时只用词库、翻译记忆和本地缓存（免费），未命中的新句子不会调用接口。
5. 也可以点「跳过，先用离线词库」，之后在「设置 → 首次设置 → 重新运行首次设置」补填。

### 已有用户与旧版本

- 已经配置过 API Key 或改过接口地址/模型的老用户**不会被首次引导打断**。
- 从 test.1 / test.2 / test.3 解压包迁移：先退出旧程序，把旧目录的 `data` 文件夹整体复制到
  新安装目录的 `data`；不要只拷其中一两个文件。程序不会自动猜测旧目录位置。
- 旧包要求手动安装 OCR；新包已内置，旧 OCR 安装器可以不再使用。

## 便携 ZIP（免安装）

1. 解压到可写目录，保留 `DeadlockTranslate.exe`、`_internal`、`ocr`。
2. 双击 `启动.vbs`（无控制台）或 `DeadlockTranslate.exe`（带日志控制台）。
3. 数据在解压目录的 `data`。移动目录时把整个文件夹一起移走。

## 数据与隐私

| 位置 | 内容 |
|---|---|
| `<程序目录>\data\config.json` | 设置与 API Key（明文保存，仅本机） |
| `<程序目录>\data\glossary.json`、`translations.json` | 词库与翻译记忆 |
| `<程序目录>\data\requests\`、`stats.json` | 请求台账与用量统计 |
| `<程序目录>\data\run.log` | 运行日志（已脱敏；仍建议贴出前自查） |

OCR 在本机完成。打开「联网翻译」后，待翻译文本会发送给你配置的服务商；
程序不发送游戏账号、密码或整屏截图，测试连接只发送固定短句。备份/恢复在设置页或
`DeadlockTranslate.exe --backup`。

## 常见问题

**安装时提示「仍在运行」**：先将设置中的「关闭窗口时」设为「退出助手」并关闭主窗口；有托盘时也可右键退出。独立设置窗口也需要关闭。
**桌面没有快捷方式**：重新运行安装器，或在开始菜单找到「锁语 · LockLingo」。
**双击后没有反应**：在安装目录运行 `DeadlockTranslate.exe --check`，按报告处理；日志在 `data\run.log`。
**杀毒软件提示未知发布者**：测试版安装包未做代码签名，请按下载页 SHA-256 核对文件；
介意时用便携 ZIP。
**怎么换接口**：设置页「翻译接口」修改；首次设置也可重新进入。修改保存后按提示重开助手。
