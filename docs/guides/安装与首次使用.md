# 安装与首次使用（锁语 · LockLingo）

下载与校验见 [GitHub 最新正式版](https://github.com/piaobo2233/deadlock-translator/releases/latest)。包内简版说明是 `先读我.md`，对应[安装版简版说明](首版测试与分享.md)。

正式安装包内置 OCR。自动检查、干净 Windows 安装包验收、显示环境及真实对局的覆盖情况分别见[测试状态](../TESTING.md)。test.3 及更早的 ZIP 仍需另装 OCR。

1.0.0 包含目录选择页与 OCR 初始化恢复改进；源码推送不会自动替换已经安装的旧包。
请选择 `D:\LockLingo` 这样的纯英文可写目录；中文安装路径仍有常驻 OCR 初始化兼容性风险。

首次设置或设置页新增「准备／更新游戏资料」，从自己的游戏安装生成名称和快捷消息资料，成功后重启。游戏更新后旧资料停用，重新准备即可；个人词库和记忆保留。详见[本机游戏资料](本机游戏资料.md)。

## 系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11，64 位 |
| 权限 | 普通用户即可，**不需要管理员权限** |
| Python / OCR | **不需要另外安装**；安装包和测试 ZIP 都自带 Python 运行环境和 OCR 运行时 |
| 翻译接口 | 自备 API Key（DeepSeek 或任意 OpenAI 兼容接口）；不填也能用离线词库 |

## 用安装包安装（推荐）

1. 下载 `LockLingo-<版本>-setup.exe`，双击运行。安装器界面为简体中文。
2. 默认安装目录 `%LOCALAPPDATA%\Programs\LockLingo`（即 `C:\Users\<用户名>\AppData\Local\Programs\LockLingo`），
   也可以改到别的可写目录；安装不需要管理员权限。
3. 安装完成后，开始菜单会出现「锁语 · LockLingo」。勾选创建桌面快捷方式时，桌面也会出现图标。可以勾选启动，或之后从快捷方式打开。
4. 如果助手正在运行，先将设置中的「关闭窗口时」设为「退出助手」，再关闭主窗口；有托盘时也可右键退出。
   安装器**不会强制关闭**正在运行的助手，也不会结束游戏。

### 升级

再次运行新版本安装包即可，会覆盖程序文件、保留个人数据。个人数据统一在
`<安装目录>\data`：配置、API Key、词库、翻译记忆、统计和审核记录。

beta.1 安装版可在设置中检查并更新至 1.0.0；便携版、源码版及 test.3 等更早版本按[软件更新](软件更新.md)手动升级。建议保持原安装目录，以沿用个人数据。

### 更换安装目录

1. 退出旧助手，将旧目录的整个 `data` 复制到独立备份位置。
2. 在新目录安装后，先保持助手退出。若新目录已有 `data`，也先单独备份，避免覆盖其中的新记录。
3. 确认要沿用哪份数据，再把保留的整个 `data` 复制到新程序目录，启动后核对设置、词库和记忆。

更改安装路径不会自动迁移旧数据。1.0.0 每次交互安装都显示目录选择页，旧路径仅作为可修改的默认值；已发布 beta.1 可能隐藏该页。

### 卸载

从 1.1.2 起，安装版可在锁语「设置 → 卸载 → 卸载锁语」确认后退出并打开卸载程序。也可以退出锁语，再从 Windows「设置 → 应用 → 已安装的应用」卸载。卸载会清理本安装的游戏联动和旧自启入口、运行缓存、更新下载及程序回退备份。

- 选「是」保留 `data` 和本机个人备份，原目录重装后可继续使用。
- 选「否」删除安装目录中的 `data`、锁语创建的个人备份和识别留档，**不可恢复**。

手动下载的安装包和另存到其他位置的导出、备份由用户自行管理。

## 首次启动

第一次启动会打开「首次设置」页：

1. **确认识别范围**。点「设置识别范围」导入完整局内截图，或截取当前游戏画面，再框出聊天范围。暂时没进游戏可先用参考范围，之后在「识别与显示」调整。
2. **选择翻译服务商**。预设「DeepSeek」会带出官方接口地址与默认模型；
   「自定义兼容接口」可自己填完整 `chat/completions` 地址和模型名。
3. **填写自己的 API Key**。密钥以明文保存在本机 `data\config.json`，界面上不回显已保存的值，
   也不会写进日志或截图。
4. 点「保存并开始」。保存本身不联网；只有你主动点「测试连接（可能计费）」才会发一次
   有超时、不重试的测试请求。
5. 回到首页后，需要在线翻译时再打开右侧「联网翻译」开关。默认关闭。
   此时只用词库、翻译记忆和本地缓存（免费），未命中的新句子不会调用接口。
6. 也可以点「跳过，先用离线词库」或「保留现有接口并开始」，之后在「设置 → 首次设置 → 重新运行首次设置」调整。

### 已有用户与旧版本

- 已完成首次设置，或已配置接口且校准过识别范围的用户，正常启动直接进入首页。
- 从 test.1 / test.2 / test.3 解压包迁移：先退出旧程序，把旧目录的 `data` 文件夹整体复制到
  新安装目录的 `data`；不要只拷其中一两个文件。程序不会自动猜测旧目录位置。
- 旧包要求手动安装 OCR；新包已内置，旧 OCR 安装器可以不再使用。

## 便携 ZIP（免安装）

1. 解压到可写目录，保留 `LockLingo.exe`、`DeadlockTranslate.exe`、`_internal`、`ocr`。
2. 双击 `LockLingo.exe`（无控制台）。`DeadlockTranslate.exe` 保留供诊断与后台 OCR 使用。
3. 数据在解压目录的 `data`。移动目录时把整个文件夹一起移走。

## 数据与隐私

| 位置 | 内容 |
|---|---|
| `<程序目录>\data\config.json` | 设置与 API Key（明文保存，仅本机） |
| `<程序目录>\data\glossary.json`、`translations.json` | 词库与翻译记忆 |
| `<程序目录>\data\requests\`、`stats.json` | 请求台账与用量统计 |
| `<程序目录>\data\run.log` | 运行日志（已脱敏；仍建议贴出前自查） |

OCR 在本机完成。打开「联网翻译」后，待翻译文本会发送给你配置的服务商；
程序不发送游戏账号、密码或整屏截图，测试连接只发送固定短句。备份/恢复在设置页或
`DeadlockTranslate.exe --backup`。

## 常见问题

**安装时提示「仍在运行」**：先将设置中的「关闭窗口时」设为「退出助手」并关闭主窗口；有托盘时也可右键退出。独立设置窗口也需要关闭。
**桌面没有快捷方式**：重新运行安装器，或在开始菜单找到「锁语 · LockLingo」。
**双击后没有反应**：在安装目录运行 `DeadlockTranslate.exe --check`，按报告处理；日志在 `data\run.log`。
**Windows 提示未知发布者**：1.1.4 安装包未做代码签名，可按下载页 SHA-256 核对文件。
**怎么换接口**：设置页「翻译接口」修改；首次设置也可重新进入。修改保存后按提示重开助手。
