# 锁语 · LockLingo 1.0.0-test.4-rc.1（源码候选）

2026-10-18。本次同步 main 源码与品牌，未新增公开二进制下载。旧 test.3/test.2/test.1 标签和附件保持不变。

## 更新

- 用户选定的 C 版双气泡品牌接入窗口、标题、冻结 exe、安装器及快捷方式配置。
- 内置 OCR 运行时的固定来源、35 文件清单和构建校验；提供当前用户安装器源码及数据保留规则。
- 首次设置支持 DeepSeek 预设、自定义兼容接口、填写自己的 Key、跳过及失败重试；复用接口页保存路径，保存不联网。
- 安装器拒绝覆盖运行中的助手/独立面板；安装输入必须通过隐私、manifest 和版本检查。
- 启动器优先查项目 Python 环境；公开导出补入品牌、OCR manifest、安装器及许可目录，排除用户 data 与私人开发材料。

## 验证与限制

本机定向 74 项中 73 通过、1 跳过，实际 OCR 清单另验通过。冻结 CLI/常驻识别合成文字、首次引导、图标及退出检查通过；未调用真实翻译 API。完整源码检查仍有已记录失败，不能宣称全量通过，详见[测试状态](../TESTING.md)。

新安装器在本执行环境中无法写系统 TEMP、当前用户快捷方式及 HKCU，失败后回滚；普通安装/重复安装/升级/卸载保留数据、干净 Windows 10/11 均待验。OCR 传递 DLL 的完整许可材料仍待核对，本地候选二进制暂不公开分发。

## 使用与数据

开发者可按[开发说明](../DEVELOPMENT.md)运行当前源码；源码版需要 Python 与 Tesseract。普通用户现有公开下载仍是 test.3，其 OCR 安装方式保持旧版说明。

名称变化不更改内部 exe 或用户数据目录。升级/迁移前退出旧程序并保留自己的 `data`；不要把私人配置、Key 或聊天记录上传到仓库。新安装流程见[安装与首次使用](../guides/安装与首次使用.md)，依赖材料见[第三方清单](../THIRD-PARTY-NOTICES.md)。
