# 锁语 1.1.1 补丁更新

- 修复首次打开时二次布局带来的中间画面，按最终窗口和字体尺寸完成布局后呈现。
- 恢复左侧主导航、子导航的液体悬停效果；移开后停止动画。
- 背景改为暖褐光影、暗角和细纸纹，统一七个功能区的纸面与控件底色，柔化词库按钮和下拉边框。
- 改进 1080p、2K、4K 与 100%–200% 缩放下的导航、输入框、开关和滑块尺寸，保留草稿和现有滚动重绘。

## 安装与更新

安装版可在“设置 → 软件更新 → 检查更新”下载完整补丁安装包并覆盖原目录；也可手动下载安装。正常退出助手后安装，保留原目录的 data。便携版完整解压，退出旧版后迁移 data。首次安装和便携版没有安装版上一版本回退入口。

## 验证范围

显示适配已通过 15 组 Tk 几何/字体模拟，七页桌面预览与相关滚动、词库、导航回归已完成。另有一个旧区域编辑器测试引用已移除属性，完整套件不记为全通过。补丁冻结包、更新发现与分发检查结果见[测试状态](../TESTING.md)。

背景为静态材质近似；真实跨显示器切换、自然对局与长期耐久仍需设备复核。未签名安装包可能显示未知发布者提示。
