# 锁语 1.0.2 更新说明

本次为截图操作与接收翻译修复补丁。

- 修复「截取当前画面」恢复窗口后，遮罩盖住编辑器并锁住鼠标的问题；范围编辑窗口可正常取消和关闭。
- 修复接收翻译在 OCR 与接口共用 4 秒硬期限时容易提前结束等待的问题。仍有效的气泡最多等待 12 秒，结果到达立即显示；过期气泡不继续显示，接口结果未知时不自动重复付费请求。
- 已过期的 OCR 任务不再继续调用识别器，避免极短超时引发不必要的常驻识别器退出和后续降级。中文复核、短词检查、多帧确认保持不变。
- 新增「设置 → 智能清理」：启动后及运行期间每天检查一次，也可立即执行。清理超过 14 天的轮转运行日志，以及有成功升级回执、校验匹配的已使用安装包。使用中、失败、未知或被修改的文件保留。
- 配置、密钥、词库、翻译记忆、请求台账、聊天记录、人工截图和程序回退备份不自动删除。这些保留资料仍可能随使用增长；智能清理不承诺应用目录总大小永远固定。

## 更新方式

安装版：设置 → 软件更新 → 检查更新 → 下载并重启更新。
源码版与便携版：查看官方下载页，按原有方式更新同一目录并保留 data。

## 验证边界

使用隔离配置、模拟接口及本地 OCR 回归验证；没有调用用户的真实付费接口。12 秒是容错上限，不是等待时间或速度承诺。真实服务延迟、全新自然对局的识别准确率提升仍需后续实测，不能以放宽截止时间代替性能验收。
