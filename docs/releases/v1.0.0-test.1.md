# 异锁聊天翻译助手 1.0.0-test.1

首个 Windows 64 位公开测试包。完整解压，无需 Python；首次自行安装包内附带的官方 OCR 安装器，在设置填写自己的 API Key 后按需开启在线翻译。

## 本版功能

- 英、西、葡、法、德聊天转中文，正文含汉字时整条跳过。
- 中文转英文，预览确认后复制，由用户自行发送。
- 本地词库与有效结果复用，未知接口结果防重复请求。
- 三帧确认、独立源图复核、可终止的常驻 OCR；修复常驻识别状态缺失导致无法退出。
- 本局实际绘制与质检共同筛选待审核。

## 实际验证与已知边界

24 项 Windows 定向检查通过；实际从最终 ZIP 启动内置依赖、冻结 OCR、独立面板，关闭主面板后助手和面板正常退出，未调用真实 API。已对包内文件逐一核验摘要，并扫描排除作者的实际 API Key。

完整开发回归仍有 9 项失败、1 项错误，以及旧回归 156/157，均与既有基线一致。不同电脑、分辨率、缩放、OCR 安装器在全新机器上的安装仍待测试；整局 90%/2 秒目标尚未验收，不将离线演示或成功样本当作达标证据。

手动翻译目标为 5 秒内完成，HTTP 等待 4.5 秒且不自动重试；网络和服务商仍可能导致失败。截图识别在本机完成，开启 API 后待翻译文字会发送给配置的服务商。
