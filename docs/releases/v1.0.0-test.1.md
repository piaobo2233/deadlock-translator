# 异锁聊天翻译助手 1.0.0-test.1

Windows 10/11 64 位测试版，测试包包含 Python 运行环境。

## 本版内容

- 通过屏幕 OCR 将英语、西班牙语、葡萄牙语、法语和德语聊天翻译为简体中文；正文含汉字时整条跳过。
- 中文转英文，预览后复制，由用户自行发送。
- 修复常驻 OCR 状态缺失导致无法退出的问题。

## 下载与使用

- `DeadlockTranslator-1.0.0-test.1-windows-x64.zip`：软件测试包。
- 同名 `.sha256`：文件校验值。

完整解压后，未安装 Tesseract OCR 的用户先运行包内安装器，再双击 `启动.vbs`。在线翻译需填写自己的 API Key，API 用量由服务商计费。

请保留 exe 和 `_internal` 文件夹，勿分享使用后生成的 `data`。测试包未签名，可核对来源及 SHA-256。

## 验证与限制

已检查测试包启动、OCR 和退出流程；检查时未调用真实 API。识别效果与翻译延迟仍需实际对局验证，网络及服务商响应会影响在线翻译。不同电脑、分辨率、缩放及全新环境下的 OCR 安装仍待验证。

安装说明见[使用指南](https://github.com/piaobo2233/deadlock-translator/blob/main/docs/guides/首版测试与分享.md)，测试记录及已知回归问题见[开发说明](https://github.com/piaobo2233/deadlock-translator/blob/main/docs/DEVELOPMENT.md)。

OCR 在本机完成；开启 API 后，待翻译文字会发送给配置的服务商。反馈请附系统、显示设置、代理情况和复现步骤，勿提交密钥、私人聊天或完整 `data`。
