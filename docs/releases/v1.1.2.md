# 锁语 1.1.2 · 完整卸载补丁

安装版的「设置 → 卸载 → 卸载锁语」会先退出助手，再打开卸载程序。也可从 Windows 应用列表卸载。卸载会移除本安装的游戏联动启动项、旧自启入口、运行缓存、更新下载和回退文件。

卸载时问到是否保留个人资料，选「否」将永久删除安装目录内的设置、API Key、词库、翻译记忆和锁语备份。需要重装时可选「是」保留资料。

安装版用户可在「设置 → 软件更新」检查更新，也可将安装包覆盖到原目录。覆盖升级保留个人资料。

隔离环境已验证 1.1.1 覆盖升级、保留资料卸载及彻底卸载后的目录清理。正式安装包的 Windows 登记、快捷方式和交互确认仍待独立环境验证。

安装包与便携版附 SHA-256 校验文件。第三方源码归档与组件映射见[第三方源码说明](third-party-sources.md)。
