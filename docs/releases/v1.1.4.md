# 锁语 1.1.4 · 卸载修复

修复从设置页发起卸载后，清理助手复用已失效的临时 Python 运行目录，导致加载 DLL 失败并中止卸载的问题。

遇到旧版卸载失败，可将 1.1.4 安装到原目录，退出锁语后从 Windows 应用列表卸载，或使用锁语的「设置 → 卸载 → 卸载锁语」。覆盖安装保留个人资料。卸载时仍可选择保留个人资料或彻底删除。

安装包和便携版附 SHA-256 校验文件。对应组件及源码见[第三方源码说明](https://github.com/piaobo2233/deadlock-translator/blob/v1.1.4/docs/releases/third-party-sources.md)。
