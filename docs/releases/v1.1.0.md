# 锁语 1.1.0 更新说明

- 设置界面默认最大化，优化滚动重绘、导航、背景和控件细节。
- 识别区域使用真实对局截图预览，支持按原图校对范围。
- 优化译文出现时的排版开销；实际对局掉帧改善仍需各设备复测。
- 费用走势适配全屏和高 DPI，完整显示坐标及首尾日期，增加峰值与选中日期标记；修复模型费用文字遮挡。
- 移除软件内手动翻译预览、复制上次输入原文按钮和多余说明，保留局内快捷操作。
- 新增安装版单版本回退：设置页及开始菜单独立恢复入口，可离线恢复本机更新前使用的版本。覆盖软件内更新和手动安装包升级，只保留一份可用上一版。
- 回退保留当前配置、词库、翻译记忆和费用/请求记录，默认跳过退掉的版本；更高版本继续提醒，也可手动重新安装。
- 改进游戏启动联动设置的失败提示和恢复处理。

## 更新方式

安装版：设置 → 软件更新 → 检查更新 → 下载并重启更新。也可下载安装包覆盖原目录。更新前正常退出助手。

本版安装器会在升级前保存旧程序；首次安装、源码版和便携版没有安装版回退入口。回退会正常关闭助手后替换程序，不强杀进程。未完成的恢复可从开始菜单继续。

## 验证范围

已完成隔离自动测试和受控安装/恢复验证，未调用真实付费接口。系统集成、自然对局帧率与长期使用效果仍依赖设备环境；安装包未数字签名。
