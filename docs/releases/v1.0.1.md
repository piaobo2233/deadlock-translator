# 锁语 · LockLingo 1.0.1

发布日期：2026-10-25。Windows 10/11 x64，内置 Python 与 OCR。

本版更新控制面板和局内译文气泡，修复滚动显示与两处控件细节。1.0.0 安装版玩家可在「设置 → 软件更新」检查并选择「下载并重启更新」。

## 变化

- 七个功能区合并为连续长页，左侧导航定位并跟随滚动，跨区保留草稿和原有操作。
- 统一暖灰背景、纸色胶囊、液体悬停、导航反馈、下拉框和控件光感；改善小窗口词库布局及居中区域编辑器。
- 主界面恢复完全不透明，处理快速滚动残影；修复开关圆钮终点及更新按钮移出后绿色不消退。
- 局内译文气泡调整为暖纸底、细墨边、内沿高光、粗体文字和同色箭头；保留定位、穿透和消息寿命。
- 程序入口模块化；发行包补充组件 METADATA 与第三方源码说明。未附带游戏字体或游戏派生词表。

## 下载与升级

- 安装版：`LockLingo-1.0.1-setup.exe`，附同名 `.sha256`。
- 便携版：`LockLingo-1.0.1-windows-x64.zip`，完整解压后运行 `LockLingo.exe`。
- OCR 对应源码：`LockLingo-1.0.1-ocr-sources.zip`；其他源码材料见 [第三方源码说明](third-party-sources.md)。

安装版请先保存草稿，并保持原安装目录。更新器校验下载、请求安全退出并备份后再安装；个人设置、词库、记忆及请求记录保留。便携版、源码版和 test.3 等旧版本需要手动升级，操作见[软件更新](../guides/软件更新.md)。

## 验证与边界

发布前检查的精确范围记录在[测试说明](../TESTING.md)。源码、冻结包与隔离安装分别验收；不把独立安装标识的夹具测试当作覆盖所有玩家设备。真实对局、长时间耐久、干净系统和完整显示配置矩阵仍未完成。

安装包未数字签名。主要支持主屏全屏/无边框；可能漏译、误识别或超时。开启 API 后仍由所选服务商计费；本版不提供自动 HUD 定位或自动发送消息。
