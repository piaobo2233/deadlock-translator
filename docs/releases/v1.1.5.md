# 锁语 1.1.5 · 英文收译紧急补丁

默认使用英文常驻 OCR。需要日语、韩语、俄语等语言时，在「识别与显示」手动开启「多语言识别（实验）」并重启。语音图标会在 OCR 前跳过。三点输入提示只加快截图，实际正文出现后才进入识别和三帧确认。本地词表补充了 `Celeste → 赛凌`。

修复试用中遇到的启动保护锁权限冲突。安装器同时检查新旧保护锁。Windows 10/11 x64 安装版可退出助手后覆盖安装到原目录，保留原有个人资料。也可下载便携 ZIP 解压使用。

试用版已完成实际对局体验和原录像回放。兼容 OCR 回退时仍可能漏掉个别消息，密集气泡下的重复显示和避让也仍需优化。

安装包、便携 ZIP 和第三方源码附件均提供 SHA-256。对应材料见[第三方源码说明](third-party-sources.md)。
