# 1.2.0 · 四语接收与稳定性修复

2026-11-15。由用户验收通过的 rc.9 升为正式版，业务代码不再调整。

## 变化

- 接收范围为英语、俄语、日语、韩语 → 简体中文，保持英文优先。改善长句、多行句子和含汉字日语的漏译。
- 已发出的请求可以在截止时间内等待同一消息恢复跟踪，避免合格译文丢失；消失、替换或过期的消息仍不显示。
- 修复窗口状态短暂不可用后采集源退出却未重新启动。正常切出暂停、切回恢复，用户不需要限制切屏次数。
- 译文中的换行先拆为实际绘制行，再计算气泡高度，修复长译文叠字。
- 发言目标语言需要明确确认；服务返回错误语种时保留原剪贴板并提示失败，不自动重复收费请求。
- 新装个人词库为 0；术语和常见缩写为独立内置参考。接收 API 返回并通过校验的中文译文自动收录，发言外语结果不混入中文词库，保留旧用户真实数据。

## 下载与升级

下载同一 Release 的 `LockLingo-1.2.0-setup.exe` 或 `LockLingo-1.2.0-windows-x64.zip`，各附 SHA-256。Windows 10/11 x64，内置 Python 和 OCR。

安装版可在「设置 → 软件更新」手动检查，或退出旧版后覆盖安装到原目录；个人数据保留。便携版解压至独立目录，勿把旧版个人数据作为公开附件上传。软件只会发现已公开的正式版，不会把本地 rc 标签作为正式更新。

## 验证与限制

rc.9 已通过相关 62 项回归、真实 Tk 两种字号的文本边界和隐藏检查，以及四次受控几何失效后的五句完整交付。受控交付使用 HTTP 边界注入，经过真实校验和持久化，不代表真实翻译服务测试。用户实际使用 rc.9 后确认可发布。

正式包由公开白名单源码重新构建，保留构建来源、文件清单和对应源码材料。发布过程的公开检查及更新发现结果在完成后补记。Windows 10/11 干净系统上的完整交互安装、应用内回退和卸载矩阵仍待验证；没有完整自然对局的漏读率和延迟统计。

对应第三方源码见同一 Release 的 OCR 与 third-party 源码附件及[源码说明](third-party-sources.md)。项目原创源码仍采用 MIT，第三方组件保留各自许可和来源。
