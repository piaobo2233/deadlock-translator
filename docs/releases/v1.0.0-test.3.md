# 异锁聊天翻译助手 1.0.0-test.3

Windows 10/11 64位测试版。本版把最近的六页导航、草稿和发言流程保护更新到Windows下载包；旧test.1/test.2及其附件保留。

## 本次更新

- 左侧分为接收翻译、发言翻译、词库、识别与显示、翻译接口、设置六页；累计诊断按需展开。
- 切页保留本次窗口期间的发言输入、译文预览与接口草稿。修改原文、语言或接口后，过期预览禁用复制。
- API地址、模型、服务商和密钥统一点击保存；区分未保存、已保存和运行时应用确认。迟到的保存/连接结果不会被当成新配置的结果。
- 发言面板用于预览与复制。游戏快捷键回填和可选自动发送仍需实际游戏验收；自动发送默认关闭。补充暂停、状态变化时的取消检查，保留原文恢复。

## 下载与升级

下载 `DeadlockTranslator-1.0.0-test.3-windows-x64.zip` 并完整解压；未安装Tesseract OCR时先运行包内安装器，再双击 `启动.vbs`。在翻译接口页填写自己的配置并保存，在接收页按需开启联网翻译。API用量由所选服务商计费。

升级前退出旧助手，在新目录解压。若要保留个人资料，只复制自己的旧 `data`；不要分享个人数据或密钥。初始ZIP不含用户配置或聊天记录。`.sha256` 文件用于核对完整包。

## 本版验证与仍有的不足

- ZIP清单、逐文件SHA-256、实际密钥排除与版本核对通过；依赖体检、冻结OCR辅助进程与离线无窗模拟退出通过。检查期间没有真实翻译API请求。
- 用户游戏结束后，实际打开并关闭新包的独立面板，核对接收、发言及接口页，并采集新版界面截图。没有启动实时识别或真实游戏发送；原生最小窗口/DPI及全部页面仍未全面验收。
- 最近源码相关检查170项：159通过、10因原生显示/钩子边界跳过、1条关闭保存回调异常用例未通过。没有宣称标准全量检查通过。发言预览另有7项定向检查通过。
- 仍可能漏译、误识别、超时，部分正常首字母大写短句可能被过滤；不承诺覆盖率、响应时间或帧率表现。旧版的实测记录不能算成本版再次验收。
- 主要面向主屏16:9全屏/无边框。副屏、超宽屏、窗口化、实际DPI与性能仍需测试。测试包未签名。
- OCR在本机完成；启用API后，待翻译文字发送给所配置的服务商。截图、完整data、API Key和私人聊天不要上传。

请带版本、分辨率与缩放、显示模式和复现步骤反馈。源码与开发说明见仓库；本项目为社区工具，与Valve无关联。
