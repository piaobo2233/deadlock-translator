# 异锁聊天翻译助手 1.0.0-test.2

Windows 10/11 64 位测试版，基于本轮实际使用反馈整理。测试包包含 Python 运行环境。

## 更新

- 设置按语言与输入、识别与显示、翻译接口、启动与关闭分组；显示仅保留字号，宽度、数量与停留由内部适配。
- 简化用量展示，修正微小费用显示，跨局保留满足质量与原始显示证据要求的待审核记录。
- 修复视觉坐标短暂失效后永久删除译文的问题：同一气泡恢复定位后可重新显示。
- 修复 `thank u`、`can u` 等短句被误拒；本地命中也保留可关联的显示诊断。

## 下载

下载 `DeadlockTranslator-1.0.0-test.2-windows-x64.zip` 并完整解压。未安装 Tesseract OCR 时先运行包内安装器，再双击 `启动.vbs`。填写自己的 API Key；API 费用由服务商计费。可用同名 `.sha256` 校验文件。

升级时先退出旧助手，在新目录解压；需要保留个人配置时，只把自己的旧 `data` 复制到新目录。不要分享个人 `data`。

## 验证与已知限制

- 开发源码通过 95 项相关回归和 19 项真实 OCR/辅助进程检查；真实接口 4 次请求成功，另验证静态游戏截图经 OCR、原图复核、API 至实际 Tk 窗口绘制以及失位恢复。
- 完整旧回归仍有 2 项失败、1 项跳过；另有关闭回调异常测试失败，未宣称全项目检查通过。测试包已验证依赖体检、冻结 OCR、独立面板关闭与离线流程退出；已有助手运行时，单实例保护正确拒绝第二个实时识别实例，因此未重复验证完整实时识别模式的启动和关闭。
- 正常首字母大写的部分英文短句仍可能被过滤，修复尚未进入本版。截图底部聊天不在当前头像栏下方识别区域内。
- 已有本机使用反馈，不代表整局无漏译、全部分辨率/DPI适配或 FPS 已验收。窗口化、副屏、超宽屏尚未校准。
- 测试包未签名。OCR 在本机运行；启用 API 后，待翻译文字会发给所配置服务商。不要上传密钥、私聊或未经脱敏截图。

使用和开发说明见仓库 README 与 `docs/DEVELOPMENT.md`。
