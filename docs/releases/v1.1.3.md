# 锁语 1.1.3 · 首次设置

- 首次设置新增「识别范围」。导入完整局内截图或截取当前游戏画面，即可框选聊天范围。没进游戏时可先用参考范围。
- 修复已有 API Key、还未校准且未完成引导时，正常启动会跳过首次设置的问题。原有接口可以继续使用。

安装版可在「设置 → 软件更新」检查并安装。更新保留原安装目录中的个人资料。更新完成后可在「设置 → 首次设置」手动打开引导。

安装包和便携版附 SHA-256 校验文件。对应组件及源码见[第三方源码说明](https://github.com/piaobo2233/deadlock-translator/blob/v1.1.3/docs/releases/third-party-sources.md)。
