# 锁语 · LockLingo 1.0.0-beta.1

这是面向真实使用反馈的公开测试版。维护者个人日常使用反馈良好；跨系统、完整显示配置、自然对局计分及 4 小时持续运行尚未完成验证，不作全面兼容或固定延迟承诺。

## 本次变化

- 接收聊天翻译、八语识别、跨语言发言、词库与审核、独立 API 用量页、更新提醒和安装版可选更新集中进入公开测试。
- 修复用量页在高缩放下的标题、数字和底部操作布局。
- 安装包内置 Python 和 OCR，无需另装这两个程序；OCR 更换为逐包固定摘要、保留许可与对应源码的 MSYS2 运行库。
- 游戏名称与快捷消息资料改为从用户自己的游戏安装生成；首次设置和设置页都有准备入口。游戏更新后停用旧资料，重新准备成功后重启生效；个人词库和记忆保留。

## 下载与开始使用

推荐 `LockLingo-1.0.0-beta.1-setup.exe`；也提供完整解压后运行的 `LockLingo-1.0.0-beta.1-windows-x64.zip`。每个附件均有 `.sha256` 文件。`LockLingo-1.0.0-beta.1-ocr-sources.zip` 是第三方 OCR 对应源码材料，普通使用无需下载。

1. 退出旧程序后安装，或把 ZIP 完整解压到可写文件夹，运行 `LockLingo.exe`。
2. 首次设置中准备本机游戏资料；成功后重启。详见[游戏资料说明](../guides/本机游戏资料.md)。
3. 填写自己的翻译接口 Key，也可跳过。联网翻译开关默认关闭；打开后，未命中的新句子会产生服务商费用。
4. **自动发送默认开启**，保留旧用户选择；请在使用游戏发言快捷键前确认该开关。关闭后只回填，检查后自行发送。

覆盖安装保留安装目录中的 `data`。从旧便携版迁移时先退出，再自行复制完整 `data`；不要上传它。新程序无数字签名，Windows 下载或启动提示仍可能出现。

Beta 标记为 GitHub Pre-release，通过下载页手动获取；现有稳定版更新检查不会自动推荐测试版，也不强制用户更新。
