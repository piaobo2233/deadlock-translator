# 1.0 大版本主要功能

用于介绍本次整合版本；其中个人区域、游戏复制译英和重新审核等为本轮新增或重做，其余为持续改进的已有能力。

1. **游戏聊天接收翻译**：本地 OCR、多帧筛选、外部字幕气泡；默认译为简体中文，支持选择接收目标语言。
2. **游戏复制中文译英**：游戏内复制中文后获取英文剪贴板结果，自行粘贴和发送；默认关闭，切出游戏取消旧输出。
3. **个人识别范围设置**：局外导入截图、拖框、缩放、局部放大、键盘微调、本地测试和显式保存；同尺寸画面启用。
4. **聊天识别与字幕改进**：数字聊天、输入动画过滤、16:10 参考范围、字幕避让与过期撤销；放不下时通过面板阅读全文。
5. **更顺畅的设置和词库**：后台校验本机游戏资料，优先展示可用条目，切页保留草稿与阅读位置。
6. **词库管理与重新审核**：编辑、导入导出和候选审核；重新审核暂停旧结果并保护后续人工修改。
7. **面板发言预览**：选择目标语言，翻译后检查、复制，自行发送。
8. **本地优先与本机游戏资料**：优先词库、记忆和缓存，按需请求 API；官方名称和快捷消息从自己的游戏安装准备。
9. **接口配置和用量统计**：DeepSeek/自定义兼容接口、显式保存、生效回执、连接测试、费用趋势和请求明细；未知费用保留未知。
10. **安装、更新和诊断**：内置 OCR、可修改安装目录、软件内更新、下载校验、退出/备份保护及默认诊断反馈。

适用范围和未完成实测见[发布说明](v1.0.0.md)。不包含自动 HUD 定位、自动游戏发言、窗口化或副屏映射。
