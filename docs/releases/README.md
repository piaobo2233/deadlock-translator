# 发布说明与检查

当前版本为 [1.0.0-beta.1](v1.0.0-beta.1.md) 公开测试版；完整游戏及跨环境验收后补。[test.3](v1.0.0-test.3.md)、[test.2](v1.0.0-test.2.md) 和 [test.1](v1.0.0-test.1.md) 为历史记录，原标签及附件保留。

后续每个版本统一使用下列结构；历史记录保留原始测试事实：

1. **变化**：具体行为、适用范围与测试状态。
2. **下载与升级**：ZIP、SHA-256、运行环境、配置与数据迁移方式。
3. **已验证**：命令、版本、环境、实际结果和检查边界。
4. **已知限制**：失败/跳过项、未测效果及需要用户自行确认的流程。

## 发布前核对

- 从干净的公开源码构建，显式指定包版本；不混入个人 data、聊天或密钥。
- 保存构建环境与实际依赖版本，不把 requirements 的最低版本当作包内版本。
- 核对组件、传递依赖、模型、字体与安装器的来源及完整许可/NOTICE；确认再分发依据，未核实事项应记录并处理，不能用致谢替代。
- 记录模型固定提交、逐文件摘要和未修改状态；记录原始 OCR 安装器来源与摘要。
- 核对新包许可证与清单、冻结启动/OCR/退出流程；原生与游戏测试单独记录。检查范围见[测试状态](../TESTING.md)。
- 使用新的注释标签与测试版说明；不覆盖已公开包，不改写历史标签。
- 上传 ZIP 和校验文件后，比对资产摘要与大小，抽查匿名下载，明确是否完整重下载。
- 同步首页、VERSION、更新日志及当前使用说明；About 使用不含固定版本号的介绍。

当前 test.3 的 ttkbootstrap、图标精确版本及安装器内部完整组件清单仍未确认，详见[第三方清单](../THIRD-PARTY-NOTICES.md)。本轮仓库整理未重新构建或更换旧附件。
