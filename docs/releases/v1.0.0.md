# 锁语 · LockLingo 1.0.0

发布日期：2026-10-21。Windows 10/11，64 位。

本版整合聊天接收、游戏复制译英、个人识别区域与控制面板改进。维护者已确认个人使用体验满足发布预期；本版通过源码自动检查与发行包检查，未完成的实机范围单独列于下文。

## 主要更新

- **个人识别区域**：导入完整原始 PNG/JPEG 或截取当前游戏画面，拖动整框/边角、缩放、局部放大、键盘微调并保存。不开游戏也可设置；仅同尺寸画面启用，尺寸不匹配时保留记录并回退参考范围。
- **游戏复制中文自动译英**：主动开启后，自行在游戏复制中文，助手确认来源后译为英文并覆盖剪贴板，用户自行粘贴和发送。新复制替换旧任务，切出游戏、暂停或关闭会取消旧输出。默认关闭。
- **接收与显示改进**：补充数字/序数词场景及输入动画过滤，改进 16:10 参考范围；译文依照原气泡寿命显示，空间不足时可在面板阅读全文。
- **设置与词库响应**：游戏资料后台校验，个人及通用词条优先呈现；重复检查去重，切页保留编辑草稿。
- **词库重新审核**：已处理记录可重新审核，暂停旧结果，保护后来人工修改，保存失败后可重试。
- **接收面板**：长文展开、全文复制、消息状态与阅读位置改进，新消息不会强制拉回正在阅读的历史位置。
- **接口、用量与诊断**：接口显式保存与生效回执，单帧本地识别测试、默认反馈诊断，保留费用未知状态；公开更新通道、目录选择及 OCR 初始化恢复改进。

完整功能名单见[1.0 功能清单](v1.0.0-features.md)。本版没有自动 HUD 定位或自动调整游戏分辨率。

## 下载与升级

- 推荐：`LockLingo-1.0.0-setup.exe`，内置 Python 与 OCR；同名 `.sha256` 用于校验。
- 免安装：`LockLingo-1.0.0-windows-x64.zip`，完整解压后运行 `LockLingo.exe`。
- 第三方对应源码：`LockLingo-1.0.0-ocr-sources.zip`；OCR 输入沿用已核对的 MSYS2 来源，包含对应源码、配方和补丁。

**beta.1 安装用户**：在设置中手动“检查更新”，阅读概述后选择更新。旧版每日后台检查可能有缓存，手动检查可刷新。旧版更新器只接收正式发布，因此本版使用 `1.0.0` 正式通道。

更新会先校验下载、请求安全退出并备份，再启动安装；不会强制结束未退出的助手。请保存草稿并保持原安装目录。便携/源码版通过下载页手动更新；test.3 及更早版本也需手动升级。改目录不自动迁移数据，操作见[安装与首次使用](../guides/安装与首次使用.md)及[软件更新](../guides/软件更新.md)。

## 已知限制

- 建议使用纯英文可写目录。安装包未数字签名，Windows 可能提示未知发布者。
- 主要支持主屏全屏/无边框；副屏、窗口化和黑边映射未支持。4K、超宽及各档 DPI 的完整实机矩阵仍待验证；16:10 参考调校不代表所有 HUD 都已验收。
- 可能漏译、误识别或超时，不承诺固定延迟、识别率或帧率。区域校准不会自动适配 HUD 字号。
- 剪贴板会被成功译文覆盖；游戏内其它用途的中文复制也可能触发。已发出的翻译请求即使取消显示，仍可能产生服务商费用。
- 未完成独立首次用户试点、自然对局计分、四小时耐久及干净系统安装/升级/失败恢复的完整矩阵。冻结检查和隔离夹具结果不能替代这些项目。

OCR 在本机执行；开启 API 后待翻译文本发送给用户配置的服务商。个人配置、密钥、词库及私有请求记录保存在本机。反馈前检查内容，不上传完整 `data` 或备份。详见[测试状态](../TESTING.md)。
