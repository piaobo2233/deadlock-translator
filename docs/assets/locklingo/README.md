# 锁语 · LockLingo / C 版品牌素材

用户已选定 C 版双气泡头像。原图由内置 imagegen 生成；本次仅做尺寸、格式导出和文字排版，未重新绘制图案。

- locklingo-master.png：选定 C 版原图，1254 × 1254，透明背景。
- locklingo.ico：Windows 多尺寸图标，包含 16、20、24、32、40、48、64、128、256 像素。
- locklingo-{尺寸}.png：11 个常用尺寸，16 至 1024 像素。
- locklingo-avatar-{512/1024}.png：为圆形裁切留出额外空间的头像。
- locklingo-wordmark-light.{png/svg}：浅色背景用中英文组合标志，深色文字。
- locklingo-wordmark-dark.{png/svg}：深色背景用中英文组合标志，米色文字。
- preview.html / preview.png：图标、圆形头像、组合标志和实际像素尺寸预览。

SVG 内嵌选定的 PNG 图标，文字保持可编辑；它不是全矢量重绘。使用系统 Microsoft YaHei 和 Bahnschrift 字体；跨系统若缺少字体，可直接使用对应 PNG。字体文件未随包分发。

原始生成提示词要点与官方参考来源见上一级 design-brief.md。此包只包含品牌素材，没有修改应用、安装器或 GitHub。
