`app/translation/game_terms.json` 由本机已安装游戏的英文/简体中文本地化文件按同一安装版本的 token 配对整理，记录来源文件、摘要和整理方式。该术语对应文件随当前源码及 test.3 包分发；它不是本项目独立创作的全部文本。源码与助手包未附原始游戏可执行程序和完整本地化文件。

## 程序交互与数据

接收端采集屏幕聊天区域并在本机 OCR；启用 API 后将待译文字发送到用户配置的服务。发言预览与游戏输入功能会使用 Windows 剪贴板，游戏快捷键流程还会执行输入与读回检查。外部浮窗和本机字体加载不等于游戏进程注入。

这些行为说明以当前实现为准，不采用旧声明中“程序只做两件事”的概括。真实游戏回填/自动发送仍待验收，其他限制见[测试状态](TESTING.md)。
