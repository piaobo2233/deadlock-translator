# B 站录制材料 · 异锁翻译助手首测

## 文件与操作

打开 `B站录屏宣传页.html`，这是包含图片的单文件，断网也能展示；实际下载按钮需要联网。推荐浏览器窗口或显示器以 1920×1080 录制。

- `F` 切换全屏，`H` 隐藏/显示顶部与底部控制条。
- `→` 或空格下一章，`←` 上一章，`Home` 回封面。
- 第二章可点击 EN / ES / PT / FR / DE 切换合成聊天示例。
- 封面用 `assets/bilibili-cover.png`；若平台需要其他比例，可在 `cards.html?card=cover` 以所需尺寸重新导出。

网页用于讲解，未接 API；气泡是功能示意，软件截图为真实窗口的演示数据。若视频还要展示实际游戏效果，请另录新一局真实画面，并遮挡昵称和比赛信息。

## 视频简介（可复制）

异锁聊天翻译助手 1.0.0-test.1 开放测试：

- 英 / 西 / 葡 / 法 / 德聊天转中文。
- 中文输入转英文，预览后复制到游戏。
- Windows 64 位，无需 Python；首次安装包内 OCR 组件，自备 API Key。

下载：https://github.com/piaobo2233/deadlock-translato/releases/tag/v1.0.0-test.1

源码：https://github.com/piaobo2233/deadlock-translato

工具开源，API 用量由服务商计费；当前为测试版，整局覆盖率和延迟仍需验证。网页气泡为功能示意，软件截图使用演示数据；项目非 Valve 官方产品。

反馈请说明系统、分辨率/缩放、显示模式、代理与复现步骤，截图遮昵称，不要发 API Key 或整个 data。
