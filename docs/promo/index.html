02 / 把回复说清

中文先写，英文再发。

先检查英文预览，再点复制。
你决定说什么，也由你粘贴发送。

输入中文→检查英文→点击复制→粘贴到游戏

修改输入会撤销旧预览；不会自动发送到游戏。

03 / 把选择留给你

能看懂，
也能自己掌握。

Windows 本地程序，源码公开。
这是一份正在打磨的玩家工具，欢迎一起发现问题。

  1. 01

    本地优先，按需联网

    本地词库和有效结果可复用；需要在线补充时，使用你自己配置的 API。

  2. 02

    结果先看，回复再发

    中文转英文保留预览和复制步骤，不替你自动发言。

  3. 03

    异常有记录，不盲目重发

    接口结果未知时保留保护，避免同一句不明不白地重复请求。

工具源码采用 MIT 许可证；API 用量由所选服务商计费，工具开源不等于 API 免费。

04 / 从这里开始

不装 Python，开始试用。

01

下载并完整解压

从 GitHub Release 获取 Windows 64 位完整 ZIP。

02

首次安装 OCR

包内附官方安装器。已有 Tesseract 可跳过。

03

填写自己的 Key

设置接口与模型，按需开启在线补充翻译。

04

打开游戏测试

双击启动，默认只在游戏前台识别聊天。

下载 Windows 测试包 ↓查看版本说明与校验 ↗

测试版仍可能漏译或误识别；整局覆盖率、2 秒目标与不同硬件表现尚待验证。手动翻译以 5 秒内完成为目标，网络和服务商仍会影响成功响应。

请分享完整 ZIP；运行后生成的 data 文件夹属于个人数据，不要重新打包发送。
